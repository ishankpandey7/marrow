Generate a save-only token in web app settings, then paste it here once.

The token stays in this browser’s extension storage. Replacing or removing it discards pending saves. A request already in flight may finish first.

One click to save

Pin the extension and click its toolbar icon on a page, right-click a link, or press Alt + Shift + S. Change the shortcut in your browser’s extension settings.

OK = saved · HAVE = already saved · Q = queued · ! = failed · AUTH = reconnect. Hover over the icon for the full message.

Queued saves retry automatically while the browser is open, including after its background worker restarts. The last result remains visible on the toolbar.

Removing a token here disconnects this browser. Revoke it in web app settings to invalidate every copy.
